# Public Results

Store release-ready public outputs here, including reports, tables, figures, and
other approved dissemination artifacts.

## Current Release Folders

- `validation/`: release validation reports.
- `data/data_examples/`: synthetic or public-safe data examples.
- `trajectories/`: aggregate social-determinant trajectory tables and figures.
- `pathway_screening/`: aggregate pathway-screening and contextual inventory
  tables and figures.
- `causal_mediation/`: aggregate causal mediation tables and figures.

## Exclusions

Do not place subject-level data, controlled-access source data, model objects,
imputation objects, draw-level files, logs, or private path manifests in these
release folders.
