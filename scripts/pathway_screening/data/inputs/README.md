# Restricted Pathway Screening Inputs

Place controlled-access pathway-screening inputs here only when running the
workflow locally with the required permissions.

Expected optional inputs:

- `pathway_inventory.md`: Markdown source containing a `## Pathway Inventory`
  section.
- `pathway_screening_raw/`: aggregate screening outputs from a controlled
  analysis run that need to be sanitised for public release.

Do not commit subject-level data, model objects, draw-level files, or private
path manifests.
