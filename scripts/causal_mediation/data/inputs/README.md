# Restricted Causal Mediation Inputs

Controlled-access causal mediation inputs should be placed here only when a
researcher has permission to run the pipeline locally. These files are ignored
for public release unless a separate written exception is approved.

Expected local inputs:

- `jmaes_strict_subject_level_analysis.rds`
- `jmaes_strict_transition_bundle.rds`
- optional imputation files under `imputations/strict_jmaes_final/`

Do not commit subject-level data, imputation objects, or fitted model objects.
