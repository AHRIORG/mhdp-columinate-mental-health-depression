Drop event images into this folder for the home page gallery.

Rules:
- Supported files: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`
- The home page uses all supported images in this folder, newest first by modified time
- The gallery shows 5 images at a time on desktop
- Manual controls let you move back, forward, or jump to a specific image
- If the folder is empty, placeholder images are shown instead

No extra file naming scheme is required.
